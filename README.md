# Ocean Explorer 3D

Exploración submarina interactiva en 3D, desarrollada por **CIOB-Mojito**.

Recorre un acuario en primera persona, observa el pez payaso animado y explora el entorno con controles táctiles pensados para Android en orientación vertical.

## Características

- Cámara de exploración libre con joystick virtual y zona de mirada táctil.
- Control independiente de altura con botones de subida y bajada.
- Pez payaso animado (GLB) con natación autónoma.
- Entorno submarino con rocas, corales, plantas y partículas.
- Colisiones simplificadas contra límites del mapa y rocas.

## Tecnologías

- [Three.js](https://threejs.org/) 0.186
- [Vite](https://vite.dev/) 8
- TypeScript
