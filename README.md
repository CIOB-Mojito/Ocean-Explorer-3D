# Ocean Explorer 3D

Exploración submarina interactiva en 3D, desarrollada por **CIOB-Mojito**.

Recorre un acuario en primera persona, observa la anémona, el pez payaso y el cardumen, y explora el entorno con controles táctiles pensados para Android en orientación vertical.

## Características

- Cámara de exploración libre con joystick virtual y zona de mirada táctil.
- Control independiente de altura con botones de subida y bajada.
- Anémona animada (GLB) como único elemento decorativo ambiental.
- Pez payaso animado (GLB) con natación autónoma y refugio en la anémona.
- Cardumen animado de ocho peces con movimiento autónomo.
- Límites de exploración del acuario.

## Tecnologías

- [Three.js](https://threejs.org/) 0.186
- [Vite](https://vite.dev/) 8
- TypeScript
